## 🚀 Featured Projects

### 🌍 FutureAir

**AI-powered air-quality forecasting for data-sparse regions.**

FutureAir explores how machine learning can estimate and forecast **PM2.5 and PM10** when environmental sensor observations are incomplete or sparse.

**Focus:**
`Machine Learning` • `Air Quality` • `Time Series` • `Sparse Data` • `Forecasting`

---

### 📡 MoleNet

**IoT-based environmental sensing and data collection.**

A sensor-based system for collecting environmental measurements and transferring them through an IoT data pipeline for storage, monitoring and machine-learning applications.

**Focus:**
`ESP32` • `Sensors` • `ThingSpeak` • `Python` • `TimescaleDB`

---

### 🧠 Air Quality Forecasting

Experimenting with different machine-learning approaches for predicting environmental variables and evaluating their performance using **MAE, RMSE and comparative experiments**.

**Models explored:**
`Gaussian Process` • `XGBoost` • `CatBoost` • `Random Forest` • `Persistence`
